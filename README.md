# PST3-IPASME-MOVIL
Aplicación móvil híbrida orientada a la gestión eficiente de citas y servicios de salud para los beneficiarios del IPASME, desarrollada bajo estándares de Ingeniería de Software con arquitectura de microservicios, Node.js, TypeScript y base de datos NoSQL (MongoDB).

Integrantes: Celeste, Ysabel, Laura.

Institución: IPASME Dr. Julio de Armas.

Tecnologías: Node.js, TypeScript, MongoDB (NoSQL).

Metodología: Ágil (Scrum).
